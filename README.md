# 봉현마을방범대 세이브 파일

- `episodes.js` : 진짜 기록. 에피소드 추가·수정은 여기서만 하면 돼요.
- `index.html` : 기록을 가로 타임라인으로 보여주는 화면. 디자인을 바꾸고 싶으면 이것만 새로 만들면 돼요.

## 에피소드 추가하는 법
`episodes.js`의 `window.EPISODES = [ ... ]` 안에 아래 모양을 하나 더 붙여 넣기.

```js
{
  date: "2017-04",          // "2017" / "2017-04" / "2017-04-21" 다 가능
  title: "제목",
  who: ["나", "지훈"],       // members에 적은 이름 그대로
  text: "있었던 일"
},
```
