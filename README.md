# 봉현마을방범대

- `episodes.js` : 진짜 기록. 이야기 추가·수정은 여기서만 하면 돼요.
- `index.html` : 기록을 보여주는 화면. 디자인을 바꾸고 싶으면 이것만 새로 만들면 돼요.

## 이야기 추가하는 법
`episodes.js`의 `window.EPISODES = [ ... ]` 맨 아래에 이 모양을 하나 더 붙여 넣기.

```js
  {
    era: "2026",                  // 맨 위 eras에 적은 이름 그대로
    title: "제목",
    who: "한나, 현주, 병준",        // 쉼표로 쭉. 검색으로 찾아져요
    text: "있었던 일"
  },
```

## 페이지가 안 뜰 때
파일에 문법 오류가 하나라도 있으면 이야기가 전부 안 보여요.
페이지 위쪽 빨간 상자에 몇 번째 줄이 문제인지 나오니까 그 줄을 확인하세요.
- text: "..." 따옴표를 닫았는지
- 따옴표 안에서 " 를 또 쓰지 않았는지 (안에서는 ' 사용)
- } 뒤에 쉼표(,)가 있는지
