# 봉현마을방범대의 밤하늘

- `episodes.js` : 진짜 기록. 썰 추가·수정은 여기서만 하면 돼요.
- `index.html` : 기록을 밤하늘로 보여주는 화면. 디자인을 바꾸고 싶으면 이것만 새로 만들면 돼요.

## 썰 추가하는 법
`episodes.js`의 `window.EPISODES = [ ... ]` 맨 아래에 이 모양을 하나 더 붙여 넣기.
적은 순서대로 별이 떠요. 처음 60개는 BB 별자리를 채우고, 그다음부터는 하늘에 자유롭게 떠요.

```js
{
  era: "스무 살 무렵",          // 맨 위 eras에 적은 이름 그대로
  title: "제목",
  who: "나, 지훈, 서연",         // 쉼표로 쭉. 검색으로 찾아져요
  text: "있었던 일",
  bright: true                  // 전설의 썰이면 (생략 가능)
},
```

## 시기 바꾸기
`episodes.js` 맨 위 `eras` 목록의 이름을 원하는 대로 고치거나 늘리면 돼요.
주의: 이름을 바꾸면 각 썰의 `era`도 같은 이름으로 맞춰 주세요.
