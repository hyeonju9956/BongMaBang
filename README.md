# 봉현마을방범대 기억 퍼즐

- `episodes.js` : 진짜 기록. 에피소드 추가·수정은 여기서만 하면 돼요.
- `index.html` : 기록을 연도 → 월 퍼즐로 보여주는 화면. 디자인을 바꾸고 싶으면 이것만 새로 만들면 돼요.

## 에피소드 추가하는 법
`episodes.js`의 `window.EPISODES = [ ... ]` 안에 아래 모양을 하나 더 붙여 넣기.

```js
{
  date: "2019-05-21",            // "2019" / "2019-05" / "2019-05-21" 다 가능
  title: "제목",
  who: "나, 지훈, 서연, 다은",    // 쉼표로 쭉. 검색으로 찾아져요
  text: "있었던 일"
},
```

## 연도 범위 바꾸기
`episodes.js` 맨 위 `startYear`, `endYear` 숫자만 바꾸면 연도 조각이 늘어나요. (2027년이 되면 endYear: 2027)
